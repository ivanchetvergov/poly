# ЛАБОРАТОРНАЯ РАБОТА № 4

## Реализованные функции

1. **Число остовных деревьев** (матричная теорема Кирхгофа)
   - Вычисляет количество остовных деревьев неориентированного графа

2. **Минимальный остов** (алгоритм Борувки)
   - Строит минимальный по весу остов неориентированного графа
   - Использует алгоритм Борувки с UnionFind

3. **Кодирование Прюфера**
   - Кодирует дерево в последовательность Прюфера
   - Сохраняет веса рёбер при кодировании

4. **Декодирование Прюфера**
   - Восстанавливает дерево из последовательности Прюфера
   - Восстанавливает исходные веса рёбер

5. **Минимальная раскраска графа**
   - Находит хроматическое число графа
   - Возвращает минимальную раскраску вершин

## Структура

- `include/` - заголовочные файлы
  - `Runner.h` - интерфейс для запуска функций
  - `Boruvka.h` - алгоритм построения MST
  - `PruferCode.h` - кодирование/декодирование
  - `KirchhoffTheorem.h` - подсчёт остовных деревьев
  - `GraphCombinatorics.h` - раскраска графов

- `src/` - реализация алгоритмов
