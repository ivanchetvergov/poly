# Graph Labs

Набор лабораторных работ по теории графов + одна по структурам данных. Все на C++20, собирается через CMake.

## Структура проекта

```bash
common/          # Общие утилиты и базовые классы
  ├── Graph.h/cc           # Основной класс графа (список смежности)
  ├── GraphGenerator.h/cc  # Генерация рандомных графов
  ├── RandomGenerator.h    # Энтити для генерации случайных чисел
  ├── PathUtils.h          # Шаблонные утилиты для работы с путями
  ├── CollectionUtils.h    # Хелперы для коллекций
  ├── MatrixPrinter.h      # Печать матриц с optional значениями
  └── Utils.h              # Разные мелочи (чтение инпута, заголовки)

lab1/    # Метод Шимбелла и подсчет путей
lab3/    # Максимальный поток и поток минимальной стоимости
lab5/    # Эйлеровы/Гамильтоновы циклы и задача коммивояжера
lab6/    # Словарь на хеш-таблице и красно-черном дереве
```

## Lab 1: Метод Шимбелла и подсчет маршрутов

**Что делает:**

- Находит минимальные/максимальные расстояния между всеми парами вершин для путей заданной длины (метод Шимбелла через перемножение матриц)
- Считает количество всех возможных маршрутов между двумя вершинами (бэктрекинг с мемоизацией)

**Основные файлы:**

- `ShimbellMethod.h/cc` — умножение матриц смежности с поиском min/max путей через template-функции
- `PathCounter.h/cc` — рекурсивный обход графа с кэшированием результатов

## Lab 3: Потоки в сетях

**Что делает:**

- Ищет максимальный поток в сети (алгоритм Форда-Фалкерсона)
- Находит поток минимальной стоимости заданной величины (Беллман-Форд в остаточной сети)
- Генерит связное дерево как основу для flow network

**Основные файлы:**

- `FlowNetwork.h/cc` — энтити транспортной сети (capacity, cost, flow)
- `MaxFlow.h/cc` — форд-фалкерсон через BFS для поиска увеличивающих путей
- `MinCostFlow.h/cc` — беллман-форд для минимизации стоимости при заданном потоке

**Особенности:**

- Использует `PathUtils` для работы с путями в остаточной сети
- `CollectionUtils` для работы с nested maps (capacity/cost/flow)

## Lab 5: Циклы и TSP

**Что делает:**

- Проверяет граф на эйлеровость (все вершины четной степени) и находит эйлеров цикл (алгоритм Hierholzer)
- Проверяет на гамильтоновость (бэктрекинг) и делает граф гамильтоновым (добавляет ребра по условию Дирака)
- Решает задачу коммивояжера через полный перебор всех гамильтоновых циклов

**Основные файлы:**

- `EulerianCycle.h/cc` — проверка эйлеровости, алгоритм Hierholzer для поиска цикла
- `HamiltonianCycle.h/cc` — бэктрекинг для поиска гамильтонова цикла
- `TSPSolver.h/cc` — full enumeration всех циклов с сортировкой по стоимости

**Как работает:**

1. Генерится случайный граф
2. Проверяется на эйлеровость → если нет, модифицируется (добавляются ребра)
3. Проверяется на гамильтоновость → если нет, модифицируется (условие Дирака)
4. Находятся все гамильтоновы циклы → выбирается с минимальной стоимостью

## Lab 6: Словарь

Реализация словаря на двух структурах данных для сравнения:

- **Хеш-таблица** (`HashTable.h/cc`) — быстрый поиск/вставка/удаление через хэш-функцию
- **Красно-черное дерево** (`RBTree.h/cc`) — балансированное BST с поддержкой упорядоченного обхода
- **Генератор текста** (`TextGenerator.h/cc`) — создает случайный текст на основе словаря

Интерактивное меню для работы со словарем + сохранение/загрузка из файлов.

## Общие утилиты (common/)

Все лабы переиспользуют код из `common/`:

- **Graph** — базовый класс графа (неориентированный, взвешенный)
- **GraphGenerator** — создает рандомные деревья и связные графы
- **RandomGenerator** — энтити для генерации случайных чисел (инты, даблы)
- **PathUtils** — template-функции для работы с путями (поиск минимума на пути, применение операций к ребрам)
- **CollectionUtils** — хелперы типа `addUnique`, `getNestedMapValue`
- **MatrixPrinter** — красивая печать матриц с optional значениями

## Требования

- C++20
- CMake 3.10+
- Компилятор с поддержкой C++20 (gcc 10+, clang 10+)

## Единое меню и запуск

В проекте реализовано **единое интерактивное меню** для всех лабораторных работ (см. main.cc). Оно позволяет:

- Генерировать и просматривать графы для Lab 1 и Lab 5
- Запускать алгоритмы Шимбелла, подсчёт маршрутов, эйлеров/гамильтонов цикл, TSP
- Генерировать отдельную сеть потоков для Lab 3 и запускать алгоритмы максимального потока/минимальной стоимости
- Работать с каждой лабораторной отдельно или через общий интерфейс

**Запуск единого меню:**

```bash
make run
```

**Запуск отдельных лабораторных:**

```bash
make run-lab1   # Lab 1
make run-lab3   # Lab 3
make run-lab5   # Lab 5
make run-lab6   # Lab 6
```

Все команды автоматически собирают нужные бинарники (через CMake и clang++), если это ещё не сделано.

## Стиль кода

- Используется современный C++20: шаблоны, лямбды, structured bindings, `[[nodiscard]]`
- Все в namespace `graph` (кроме lab6 — там `dict`)
- Entity-классы для инкапсуляции логики (RandomGenerator, FlowNetwork, etc.)
- Максимальное переиспользование кода через утилиты
