# Документация по Python скриптам визуализации

Этот документ описывает Python скрипты в `scripts/visualization/`, используемые для генерации визуализаций данных из C++ алгоритмов графов.

## Обзор

Скрипты читают данные, экспортированные C++ классами (например, Graph, HashTable) из текстовых файлов в `assets/txt/`, обрабатывают их и генерируют PNG изображения в `assets/png/` с помощью matplotlib и networkx.

## Общее использование

Все скрипты вызываются из C++ через `python -m scripts.visualization.plot_<type> <input_file> <output_file> <title>`

- `<input_file>`: Путь к txt файлу с данными (например, `../../assets/txt/hashtable_demo.txt`)
- `<output_file>`: Путь к выходному PNG (например, `../../assets/png/hashtable_demo.png`)
- `<title>`: Заголовок графика

## Скрипты

## plot_hashtable.py

**Назначение**: Визуализировать HashTable как слова -> бакеты -> цепочки.

**Формат данных**: Строки вида `word hash bucket`

## plot_rbtree.py

**Назначение**: Визуализировать RBTree как дерево с корнем сверху.

**Формат данных**: Строки вида `node parent color` (color: RED/BLACK)

## plot_colored_graph.py

**Назначение**: Визуализировать раскрашенные графы (например, из алгоритмов раскраски графов).

**Формат данных**: Строки вида `node color` или `node x y color` (узлы с цветами).

## plot_flow_animation.py

**Назначение**: Анимировать сети потоков (шаги максимального потока).

**Формат данных**: Множественные кадры, каждый с рёбрами и потоками (например, `u v capacity flow`).

**Особенности**: GIF анимация роста потока.

## plot_matrix.py

**Назначение**: Визуализировать матрицы (смежности, весов и т.д.).

**Формат данных**: Матрица как текст.

**Особенности**: Тепловая карта или сетка.

## plot_network.py

**Назначение**: Общая визуализация графов.

**Формат данных**: Список рёбер вида `u v weight`.

**Особенности**: Макет пружин, настраиваемый.

## plot_paths.py

**Назначение**: Визуализировать пути в графах.

**Формат данных**: Пути как `node1 node2 ...` или выделенные рёбра.

**Особенности**: Раскрашенные пути.

## plot_text_stats.py

**Назначение**: Визуализировать статистику текста (например, из TextGenerator).

**Формат данных**: Строки вида `key value`.

**Особенности**: Столбчатые диаграммы и т.д.

## Зависимости

- matplotlib
- networkx

Установить через `pip install matplotlib networkx`

## Конфигурация

Скрипты используют `scripts.core.config` для настроек:

- `plot_cfg`: figsize, dpi, title_font_size, etc.
- `node_cfg`: node_color, node_size
- `edge_cfg`: arrow_style, default_edge_color, etc.
- `label_cfg`: настройки шрифта

## Расширение

Чтобы добавить новый скрипт:

1. Создать `plot_<new>.py` в `scripts/visualization/`
2. Реализовать `main()` с argparse или sys.argv
3. Читать данные, строить граф, рисовать, сохранять.
4. Обновить C++ Visualizer для вызова.
