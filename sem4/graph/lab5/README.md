# ЛАБОРАТОРНАЯ РАБОТА № 5

## Что реализовано

1. Для неориентированного графа:
 - проверка эйлеровости;
 - если граф не эйлеров, его модификация до эйлерова с логированием добавленных рёбер;
 - построение и визуализация эйлерова цикла.

2. Для неориентированного графа:
 - построение кратчайшего остова (алгоритм Борувки из Lab 4);
 - построение фундаментальной системы разрезов по рёбрам остова;
 - получение разреза как симметрической разности выбранных фундаментальных разрезов.

## Команды меню

- `51` — Эйлеровость, модификация и эйлеров цикл
- `52` — Фундаментальные разрезы и симметрическая разность
